Put optional ChatGPT usage CSV/JSON files here.

Recommended CSV columns:
timestamp,source,kind,model,prompt,credits,input_tokens,cached_input_tokens,output_tokens,reasoning_output_tokens,total_tokens

Example:
2026-08-28T14:30:00Z,chatgpt,chat,GPT-5.6 Sol,"Explain this error",10,,,,,

For ChatGPT fixed-credit messages, leaving credits blank uses the value configured in ../config.json.
